# Тексер — ИИ-проверка БЖБ/ТЖБ по дескрипторам

Цепочка: фото работы → ИИ оценивает каждый дескриптор и пишет подсказку по первой ошибке → учитель правит и утверждает → карта ошибок класса, «что разобрать на уроке», баллы в CSV.

## Запуск
1. Node.js 20+ (nodejs.org).
2. В папке проекта: `npm install`
3. Скопировать `.env.example` в `.env`, вписать `OPENAI_API_KEY`.
4. `npm start` → http://localhost:3000

Без ключа работает демо-режим: работы А/Б/В и демо-класс; загрузка своих фото отключена.

## Устройство

### Своё задание: «Любой СОР/БЖБ»

На рабочем столе откройте «Любой СОР/БЖБ», введите название, условие, эталон и дескрипторы — по одному на строку, каждый на 1 балл (до 30). Сохраните задание, загрузите 1–4 фото работы и утвердите результат. Для следующих учеников выбирайте это задание в списке. Проверка фото требует API-ключа; без ключа можно подготовить задание и пройти встроенное демо.

Вместо ручного ввода можно загрузить 1–4 фото листа заданий, необязательно добавить до 4 фото и/или текст критериев и ключа, затем нажать «✨ Подготовить с ИИ». Условие можно также ввести текстом в поле ниже. Фотографии сжимаются перед отправкой. ИИ переписывает переданные критерии/ключ, а недостающие ответы и дескрипторы предлагает самостоятельно. Поля заполняются с пометкой «Предложено ИИ — проверьте перед использованием»: отредактируйте их и сохраните обычной кнопкой. Автоматического сохранения нет. Для этой подготовки нужен API-ключ; она использует ту же модель и общий лимит, что и проверка работ. Фото на сервере не сохраняются.

Свои задания и утверждённые результаты хранятся только в текущем браузере. При недоступном хранилище задание доступно до перезагрузки, о чём появляется сообщение. Карта ошибок и счётчик доверия ведутся отдельно для каждого задания; ошибки своего задания соответствуют незачтённым дескрипторам. `data/tasks.json` менять не нужно, фото на сервере не сохраняются.

Серверные тесты без обращений к OpenAI: `npm test`.
- `server.js` — Express; `/api/check` отправляет фото в OpenAI (structured output по дескрипторам). Фото не сохраняются. Лимит своих фото — 5 в час с адреса.
- `public/index.html` — страница учителя (РУС/ҚАЗ), без сборки.
- `data/tasks.json` — задания, эталоны, дескрипторы, коды ошибок с советами к уроку. `data/demo.json` — вымышленные работы и класс.
- `AGENTS.md` — правила для Codex; `docs/codex-tasks.md` — задания для Codex.

## Данные
Только вымышленные или обезличенные работы; ученики — коды У-01, У-02…; ключ — только в `.env` на сервере.
