# AGENTS.md — правила проекта «Тексер» для Codex

Тексер — сайт для учителя математики: ИИ проверяет фото работы БЖБ/ТЖБ по дескрипторам, учитель утверждает, сайт строит карту ошибок класса.
Конкурс Codex Challenge (BilimAI). Рецензент должен пройти демо за 3–5 минут без помощи автора.

## Стек
- Node.js 20+, Express 4, ES-модули. Без сборки фронтенда: `public/index.html` (HTML + CSS + JS в одном файле).
- Данные: `data/tasks.json` (задания, дескрипторы, коды ошибок), `data/demo.json` (вымышленные работы и класс).
- ИИ: OpenAI Responses API, модель из `OPENAI_MODEL` (по умолчанию gpt-6.1-sol), structured output по JSON-схеме в `server.js`.

## Правила
1. Один главный путь: работа → проверка → утвердить → карта ошибок → добивка. Новые функции встраиваются в этот путь, не добавляя разделов меню.
2. Интерфейс на русском и казахском: каждую новую строку добавлять в оба словаря `T.ru` и `T.kk`.
3. Работает с телефона (ширина 375 px) и без ключа API (демо-режим).
4. Никаких персональных данных: ученики — коды У-01, У-02…; ключи только в `.env`, никогда в коде и коммитах.
5. Подсказка ученику — только к первой ошибке, без готового ответа.
6. Не добавлять зависимостей без необходимости. Не менять схему ответа ИИ без обновления промпта и демо-данных.
7. Перед PR: `npm start`, открыть http://localhost:3000, пройти демо-работы А, Б, В — без ошибок в консоли.
