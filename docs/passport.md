## 1. Паспорт проекта

| Поле | Содержание |
|---|---|
| Название | Тексер — ИИ-проверка БЖБ/ТЖБ (СОР) по дескрипторам |
| Автор | Тынышбек Әнуарбеков, учитель математики, Ақтөбе БИЛ |
| Направление | Мектеп/Школа |
| Проблема и пользователь | Учитель математики тратит часы на проверку рукописных БЖБ/СОР по дескрипторам и почти не успевает увидеть, какие ошибки типичны для класса. Пользователь — учитель математики 5–11 классов. |
| Основной сценарий | Старт — «Рабочий стол учителя»: расписание недели; из урока с БЖБ/СОР учитель переходит к проверке. Вход: фото рукописной работы ученика (1–4 страницы). Действие: ИИ определяет вариант по номеру на листе, отмечает каждый дескриптор, находит первую существенную ошибку и пишет подсказку без готового ответа; учитель правит и утверждает. Результат: балл по дескрипторам, подсказка ученику, карта ошибок класса и что разобрать на следующем уроке, баллы в CSV. |
| Форма продукта | Веб-приложение (сайт), без установки и без входа. |
| Отличие от аналогов | Сканеры бланков (OMR) проверяют отмеченные кружки. Тексер проверяет ход рукописного решения и превращает проверку в план следующего урока. |
| AI-инструменты и вклад | Claude (Anthropic) — архитектура и версия v0.1, промпт проверки; Codex (OpenAI) — счётчик доверия (% работ, утверждённых без правок) и рабочий стол с расписанием и карточками уроков (сделаны 16.11), «добивка» — к 20.11; модель проверки — OpenAI gpt-6.1-sol (Responses API, structured output). Автор — задания, ключи и 20 дескрипторов СОР 1 «Integer Exponents» (варианты 21, 22, 25), коды типичных ошибок и советы к уроку, проверка качества на реальных работах. |
| Среда и зависимости | Node.js 22, Express 4 (MIT); сервер Hetzner (Debian); OpenAI Responses API. Затраты: сервер 5,49 € в месяц (общий с другими проектами автора); API — около 1–2 центов за работу, предоплата $5 с жёстким лимитом. |
| Данные и ограничения | Фото отправляется в OpenAI только для проверки и на сервере не сохраняется. Ученики обозначены кодами (У-01…), в демо — только вымышленные данные. Утверждённые результаты хранятся в браузере учителя. Ограничения: нужен разборчивый почерк и хороший свет; ИИ может ошибиться, поэтому решение всегда за учителем; не более 5 своих фото в час с одного адреса. **Имитируется:** расписание и класс 7«А» вымышленные; «Демо-класс» (24 ученика) и его карта ошибок построены на вымышленных данных; работы А/Б/В — заранее сохранённые результаты ИИ по вымышленным работам (живая проверка — тест 2); ссылки на презентации — заглушки; сообщение ученику никуда не отправляется. Реально работает: проверка загруженных фото ИИ, правка и утверждение учителем, карта ошибок по утверждённым работам, CSV. |

## 2. Задание для тестирования MVP (3–5 минут, без входа)

**Тест 1 — демо без загрузки (1 мин).**
1. Откройте http://167.233.123.181:8087
2. На рабочем столе нажмите «Среда · БЖБ» → «Проверить БЖБ/СОР».
3. Нажмите «Работа Б · У-02».
4. Ожидаемый результат: 3 из 5; не засчитаны D1 и D2; первая ошибка в задании 1 — (−3)⁻² вычислено как −1/9; подсказка спрашивает о знаке, но не даёт ответа.
5. Нажмите «✓ Утвердить» — внизу появится карта ошибок и совет к уроку.

**Тест 2 — проверка работы ИИ (2–3 мин).**
1. Скачайте 2 страницы образца (вымышленный ученик, вариант 25):
   - https://github.com/rightways94-prog/tekser/raw/main/test/variant25-page1.jpg
   - https://github.com/rightways94-prog/tekser/raw/main/test/variant25-page2.jpg
2. На рабочем столе нажмите «Пятница · СОР» → «Проверить БЖБ/СОР» (задание «Summative Assessment 1 · Integer Exponents» выберется само).
3. Нажмите «📷 Загрузить фото работы» и выберите обе страницы сразу. Подождите 10–30 с.
4. Ожидаемый результат: вариант 25 определён автоматически; 11 из 20; не засчитаны D3, D5, D6 (задание 2: коэффициент 2 не возведён в квадрат, не указаны a ≠ 0, b ≠ 0), D7, D9 (2⁰ = 0), D14–D16 (потерян знак знаменателя −2), D18 (12,5·10⁵ — не стандартный вид); первая ошибка — задание 2.
5. Признаки качества: вариант определён без подсказки; ошибки названы конкретно; подсказка короткая и не раскрывает ответ; учитель может поправить галочки и подсказку перед утверждением.

**Тест 3 — карта ошибок (30 с).** «Демо-класс»: доля учеников с каждой ошибкой и два совета, что разобрать на уроке. «⬇ Баллы в CSV» — таблица утверждённых работ.

**Результат проверки автором (15.11 и 16.11):** на образце из теста 2 ИИ совпал с эталоном по 20 из 20 дескрипторов, проверка заняла 15–16 секунд.
