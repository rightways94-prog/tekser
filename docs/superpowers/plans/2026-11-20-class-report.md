# Сводка и единая шкала пачки

- [x] Сервер: первая распознанная работа создаёт referenceTask один раз. Следующие запросы передают её, распознают/решают вариант без генерации новых дескрипторов. При том же варианте сохраняется первый эталон; при другом решается его условие. Несовместимые задания отмечаются ошибкой, максимум не меняется.
- [x] Клиент: шкала сохраняется при остановке/повторе; если она распознана до ошибки проверки, сохраняется и при этой ошибке. Если первую работу нельзя распознать, очередь останавливается до её исправления.
- [x] Отчёт: число проверенных, средний процент, минимум/максимум, пять интервалов гистограммы; топ-3 ошибок с подсчётом уникальных учеников и урок на основе имеющихся подсказок. Основная группировка — общие дескрипторы, близкие категории объединяются.
- [x] Компактная таблица открывает прежнюю карточку. Условие/эталон доступны в ней; просмотр всех фото и замена ошибочных фото остаются.
- [x] Утверждение всех сохраняет правки, связывает записи и задания общей меткой пачки для mine(), карты и счётчика. Печать выводит только отчёт без кнопок/фото.
- [x] Проверки: серверные и чистые функции сводки, браузер по HTTP на IP (небезопасный контекст), РУС/ҚАЗ, 375 px, печатные стили и прежние функции. Ответы ИИ в тестах подменяются.

## Проверки

- `npm test`: 31/31. Общая шкала создаётся один раз; тот же вариант использует исходный ответ, другой — новый ответ при тех же дескрипторах. Несовместимый вариант не получает оценку. Шкала сохраняется и после ошибки первой проверки.
- Браузер по HTTP на IP, isSecureContext=false, РУС/ҚАЗ, 375 px: среднее/диапазон/гистограмма, объединение ошибок без повторного подсчёта ученика, подсказки, компактная таблица, правки, массовое утверждение, общая карта и счётчик, печать без фото/кнопок.
- Сохранены остановка/продолжение, замена плохих фото, CSV, ручное задание, подготовка с ИИ, демо А/Б/В и пример фото.
- Исправлено замечание ревью: отдельная загрузка из карточки пачки резервирует номера всех работ, включая ещё не утверждённые. Падающая браузерная регрессия после исправления проходит.
- В компактной таблице выводится только первая ошибка; CSV сохраняет полный список критериев с ошибками.
