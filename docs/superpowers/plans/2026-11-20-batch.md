# Проверка пачки работ

Цель: загрузить фото класса с напечатанными условиями, проверить работы и получить редактируемый учителем отчёт без изменения старых сценариев.

Принятые допущения: до 30 работ за раз, по 1–4 страницы на работу. По умолчанию страницы группируются последовательно по две, учитель может изменить число страниц и номер группы у каждого фото до запуска. Имена не распознаются для идентификации: используются коды У-01 и далее.

Проверка идёт по одной работе: сервер распознаёт именно её печатное условие и строит эталон, затем проверяет решение по полученным дескрипторам. Рукописное решение ученика запрещено принимать за ключ. Это позволяет обрабатывать разные варианты. Неудача одной работы не превращается в нулевой балл и не удаляет успешные результаты.

Архитектура: POST /api/batch-check {images,rubricText,lang} возвращает {task,result} для одной работы. Фото сжимаются браузером и не сохраняются сервером. Отдельный BATCH_LIMIT_PER_HOUR (по умолчанию 30 работ) ограничивает расходы; старый общий лимит одиночных проверок и подготовки задания не меняется. Одновременно выполняется один запрос пачки. Остановка завершает текущую работу, затем позволяет продолжить.

Отчёт содержит код, балл/максимум, процент, первую ошибку и подсказку. Результат открывается в существующей карточке проверки для правок и утверждения. У каждого результата своё локальное задание: статистика разных вариантов не смешивается. CSV позволяет выгрузить весь отчёт; необработанные и ошибочные работы явно обозначены. Фото и незавершённая очередь живут только в текущей странице.

## Проверки и решения

- Допущение о группировке: по две страницы подряд по умолчанию, с выбором 1–4 и ручным назначением номера ученика у каждого фото. Необязательное уточнение осталось без ответа; имена и границы работ не угадываются автоматически.
- Отдельный бюджет пачки выбран в работах, а не одиночных вызовах API: по умолчанию 30 попыток в час с IP, по два вызова ИИ на работу. Старый лимит 5 действий в час сохраняется для одиночных сценариев.
- `npm test`: 23/23. Браузерные тесты сохранены в test/batch-browser.py и test/batch-edge-browser.py.
- Подтверждены 10 фото → 5 работ, группировка 4+1, остановка/продолжение, сохранность успешных результатов при ошибке, замена ошибочных фото, повтор только непроверенных, CSV, утверждение и изоляция статистики, РУС/ҚАЗ, 375 px.
- Замечания ревью исправлены: замена фото без сброса отчёта; просмотр всех страниц перед утверждением. Оба случая воспроизведены падающими тестами, после исправления тесты проходят.
- Дополнительная регрессия: очистка пачки не оставляет ссылок на удалённые предпросмотры при смене языка. Крупный просмотр обычных фото также использует корректные blob-ссылки.
- Реальные ответы OpenAI не проверялись без API-ключа: тесты используют подмену ответов и проверяют маршруты, промпты и интерфейс. Нечитаемая работа возвращает ошибку, а не нулевой балл.
