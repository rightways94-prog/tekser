# Любой СОР/БЖБ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Проверять задание учителя без редактирования data/tasks.json.

**Architecture:** Ручной ввод условия, эталона и дескрипторов (одна строка — один балл), затем существующий путь загрузки фото, проверки и утверждения. Задания сохраняются в localStorage с уникальными идентификаторами; сервер проверяет переданное определение и использует существующий формат ответа ИИ.

**Tech Stack:** Node.js, Express, HTML/CSS/JS без новых зависимостей.

**Spec:** Запрос пользователя в этой сессии; допущение до ответа на уточнение — ручной ввод, без распознавания фото задания.

## Global Constraints

- Сохранить встроенные задания, демо А/Б/В, пример фото, расписание и счётчик доверия.
- РУС/ҚАЗ через T.ru/T.kk, мобильная ширина 375 px.
- Фото не сохранять; data/tasks.json и схему ответа ИИ не менять.

## Review Focus

- Разные задания не смешивают утверждённые работы и статистику.
- Недоступный localStorage не ломает интерфейс.
- Некорректное определение задания отклоняется сервером.
- Текст учителя отображается как текст, а не HTML.
- Незавершённое создание задания не позволяет отправить фото без критериев.
