# Тексер — инструкция для рецензента (итоговый пакет)

Codex Challenge · Мектеп/Школа · автор: Тынышбек Әнуарбеков, учитель математики, Ақтөбе БИЛ
**Проект:** http://167.233.123.181:8087 — без входа, регистрации и оплаты; телефон или компьютер.
**Код:** https://github.com/rightways94-prog/tekser · **Паспорт проекта:** https://github.com/rightways94-prog/tekser/blob/main/docs/passport.md

## 1. Чья проблема и что делает проект
Учитель математики проверяет рукописные БЖБ/СОР по дескрипторам вручную: на класс уходят часы, а какие ошибки типичны для класса, видно только «на глаз». Тексер принимает фото работы (1–4 страницы), сам определяет вариант, отмечает каждый дескриптор, находит первую существенную ошибку и пишет ученику подсказку без готового ответа. Учитель правит и утверждает — решение всегда за ним. По утверждённым работам Тексер строит карту ошибок класса, советует, что разобрать на следующем уроке, и выгружает баллы в CSV.

## 2. Как пользоваться
1. Откройте сайт. Главный экран — «Рабочий стол учителя»: расписание недели 7«А».
2. Нажмите урок с оцениванием («Среда · БЖБ» или «Пятница · СОР») → «Проверить БЖБ/СОР».
3. Откройте демо-работу (А/Б/В) или нажмите «📷 Загрузить фото работы» и выберите 1–4 страницы одного ученика.
4. Через 10–30 с появятся: вариант, балл, галочки по дескрипторам с комментариями, первая ошибка, подсказка.
5. Исправьте галочки или подсказку, если не согласны, и нажмите «✓ Утвердить».
6. Внизу — «Карта ошибок класса»: доля учеников с каждой ошибкой и что разобрать на уроке; счётчик доверия — сколько работ утверждено без правок.
7. «⬇ Баллы в CSV» — таблица для журнала.

Доступ: открыт всем, оплата не нужна. Ограничения: не более 5 своих фото в час с одного адреса (защита бюджета; демо-работы без лимита); нужен разборчивый почерк и хороший свет; утверждённые работы хранятся в браузере учителя.

## 3. Тест на 3–5 минут
**Исходные данные:** 2 страницы СОР вымышленного ученика (вариант 25) с заранее заложенными ошибками —
https://github.com/rightways94-prog/tekser/raw/main/test/variant25-page1.jpg и https://github.com/rightways94-prog/tekser/raw/main/test/variant25-page2.jpg
**Действия:** скачать обе картинки → на сайте «Пятница · СОР» → «Проверить БЖБ/СОР» → «📷 Загрузить фото работы» → выбрать обе страницы сразу → подождать ~15 с → «✓ Утвердить».
**Ожидаемый результат:** вариант 25 определён сам; 11 из 20; не засчитаны D3, D5, D6, D7, D9, D14, D15, D16, D18; первая ошибка — задание 2 (коэффициент 2 не возведён в квадрат); после утверждения работа появляется в карте ошибок.
**Признаки качества:** вариант определён без подсказки; ошибки названы конкретно; подсказка короткая и не раскрывает ответ; учитель может поправить любую галочку.
Быстрый вариант без загрузки (1 мин): «Среда · БЖБ» → «Проверить» → «Работа Б · У-02» → ожидается 3 из 5, ошибка в знаке (−3)⁻², подсказка без ответа.

## 4. Польза — реальные цифры
- **Время:** 5 работ СОР вручную — [ЗАМЕР] мин; те же 5 с Тексером (загрузка, просмотр, правка, утверждение) — [ЗАМЕР] мин. Экономия ≈ [ЗАМЕР] мин на класс из 25 учеников.
- **Точность:** на тестовой работе (п. 3) ИИ совпал с учителем по 20 из 20 дескрипторов. На 3 реальных работах 7 класса (обезличены, в пакет не входят) — совпало [ЗАМЕР] из 60 дескрипторов; первая ошибка найдена верно в [ЗАМЕР] из 3.
- **Результат для урока:** карта ошибок сразу показывает 2 темы для разбора — раньше на это уходил отдельный разбор стопки работ.

## 5. Как использовать в другой школе
Тексер — сайт, ничего ставить не нужно: учитель любой школы открывает ссылку с телефона. Меняется только файл заданий `data/tasks.json`: условия, ключи по вариантам, дескрипторы и коды типичных ошибок — их готовит сам учитель или методобъединение один раз на БЖБ/СОР (≈30 мин), затем файл используется всеми учителями параллели. Подходит любая четверть и класс, где ответ пишется от руки и оценивается по дескрипторам; язык интерфейса — русский или казахский. Для запуска своей копии нужен любой сервер с Node.js 22 (инструкция в README, ~15 мин) и ключ OpenAI API: проверка одной работы стоит около 1–2 центов, лимит расходов задаётся в кабинете OpenAI. Фото на сервере не сохраняются, ученики обозначаются кодами, поэтому персональные данные не накапливаются. Итог всегда утверждает учитель — ИИ может ошибиться на неразборчивом почерке. Ограничение: пока поддерживается математика с проверкой по эталону; для предметов с развёрнутыми текстовыми ответами нужна доработка критериев.

**ИИ-инструменты и вклад:** архитектура и v0.1 — Claude (Anthropic); счётчик доверия и рабочий стол с расписанием — Codex (OpenAI); модель проверки — OpenAI gpt-6.1-sol. Задания, ключи, 20 дескрипторов СОР, коды ошибок, советы к уроку и проверка качества — автор. **Имитируется:** расписание и класс 7«А», «Демо-класс» и работы А/Б/В — вымышленные данные; ссылки на презентации — заглушки.
